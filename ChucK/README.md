# ChucK Sound Engine

This directory contains the ChucK programs developed for LUMEN.

## Versions

### LUMEN V2.0 — Initial Implementation
The first six-sensor implementation, featuring six individual sound personalities.

### LUMEN V2.5 — Organic Mode
Introduced ambient harmonies, smoother brightness response, and light-triggered musical events.

### LUMEN V2.6 — Organic Soundscape
Refined the sound engine with improved ambient textures, smoother transitions, and event cooldowns.

## Development

These versions document the evolution of LUMEN's sound-generation system, from its initial implementation to the latest organic soundscape.
